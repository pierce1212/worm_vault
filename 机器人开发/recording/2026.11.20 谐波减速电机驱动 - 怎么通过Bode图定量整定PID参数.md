# 谐波减速电机驱动 - 怎么通过Bode图定量整定PID参数

**前提痛点**：凭手感试凑 PID—— 比例大了震荡，调小了又软绵绵。正确做法是先扫出平台真实 Bode 图，再在频域定量算参数。

### 1. 扫频体检：测出平台特性 G (jω)

- 向平台送入不同频率的正弦波激励，逐频点对比输入与输出；
- **低频**：输出几乎原样跟随（示例 1.5 Hz，幅值比 +4.0 dB，相位滞后 −6°）；
- **高频**：受惯性和延时影响，幅值衰减、相位滞后加大；太快就甩不动，还会暴露**机械谐振尖峰**（示例 260 Hz，−2.5 dB，相位 −278°）；
- 把各频点的幅值、相位连起来，得到平台特性 G (jω)。

### 2. 频域为什么好算：串联 "乘变加"

- 时域是复杂的微分方程卷积；到了对数 Bode 图上，串联控制器 C 与平台 G：
    - **L(dB) = C(dB) + G(dB)**，**∠L = ∠C + ∠G**
- 目标：用控制器曲线往上叠，把开环曲线 L (jω) 捏成理想形状。

### 3. 评判系统的两把尺子

表格

|指标|含义|工程取值|
|---|---|---|
|穿越频率 ωc（0 dB）|越高响应越快|在稳的前提下尽量右推|
|低频增益|越高稳态误差越小||
|**相位裕度 PM**|距 −180° 正反馈悬崖的安全距离|**PM = 180° + ∠L (ωc)，通常 45°~60°**|
|增益裕度 GM|一般要求 GM ≥ 6 dB||

- 相位掉到 −180° 时，负反馈 × 反相 = 正反馈，系统直接失控震荡；
- **PM≈15°**：贴近悬崖，大幅超调、持续震荡；**PM≈55°**：微超调、干脆收敛；
- **黄金法则**：保证 PM 在 45°~60° 的前提下，再把 ωc 尽量往高（右）推。

### 4. 定量反解 Kp、Ki（三步）

1. 定目标穿越频率 ωc 和目标裕度（示例 ωc = 60 Hz，PM = 55°）；
2. 在平台曲线上读出该频点的**幅值缺口**（示例 4.3 dB）和**相位缺口** θc（示例 −34°）；
3. 画复平面矢量三角形，控制器幅值 |C| = 1/|G|：
    - **Kp = cos(θc) / |G|**（水平投影）
    - **Ki = −ωc·sin(θc) / |G|**（垂直投影）

### 5. 高频谐振处理：先 Notch 再解参数

- 若高频冒出机械谐振尖峰，先用 **Notch 陷波器**把尖峰压到 0 dB 以下（精准手术刀，只挖 260 Hz 尖峰，不影响其他频段），再解 PID，避免高频啸叫；
- 补充：**零极点对消（内模控制）**—— 先拟合电机主极点 R/L，令 **Ki/Kp = R/L** 抵消极点；再凭延时 Td 估算最大 ωc。适用位置环、倒立摆、磁悬浮等。

### 6. 实战避坑

- **开环不稳的对象**（位置环、倒立摆、磁悬浮）扫频三步：
    1. 先用保守低增益闭环稳住，哪怕慢，先保证不倒、不飞车；
    2. 在闭环中注入正弦扰动，扫出灵敏度函数 **S = 1/(1+C·G)**；
    3. 代数反推出 G (jω)，再重算 PID。
- **扫频必须用小信号**：激励太大会触发电压 / 电流限幅饱和失真；太小又会被传感器噪声淹没。
- **相角决定带宽天花板**：延时大、相位快速跌向 −180° 时，强行加大 Kp 只会导致高频震荡；要靠**减延时或加前馈**破局。
- **破局三件套**：① 压缩采样与控制延时；② 陷波器砍掉机械谐振；③ 叠加前馈抢先一步。

## 二、完整口播文案

很多人调整 PID 都是凭手感试凑，比例大了就震荡，调小了又软绵绵。其实只要先扫出平台的 Bode 图，摸清真实脾气，就能一次把 PID 算准。

**原理很简单**：往平台里送不同频率的正弦波，看它跟不跟得上。低频慢慢推，输出几乎原样跟着动；频率升高后，惯性和延时让输出变小、慢半拍，这就是幅值衰减和相位滞后。摇得太快就彻底甩不起来，还会暴露机械谐振尖峰；把各频点连起来，就能测出平台特性 G (jω)。

**为什么在频域更好算**：因为串联时控制器乘以平台，到了对数 Bode 图上，直接变成两条曲线上下相加。你的目标特别明确：用控制器曲线往上叠，把开环曲线 L (jω) 捏成理想形状。

**系统看两个标尺**：0 dB 穿越频率 ωc 越高，响应越快；低频增益越高，稳态误差越小。更重要的是相位裕度 PM—— 相位一旦掉到 −180°，负反馈就反相成正反馈，系统直接失控震荡。所以工程上通常在穿越频率处留出 45° 到 60° 安全距离，既快又稳不震荡。

**定量计算分三步**：先定好目标穿越频率 ωc 和 55° 裕度，再去平台曲线上读出幅度和相位的缺口。知道了控制器需要补多少倍、偏多少度，画出复平面矢量三角形，水平投影就是 Kp，垂直投影直接算出 Ki。

**如果高频冒出机械谐振尖峰**，先盖一个陷波器把尖峰压到 0 dB 以下，再解参数，就能彻底告别高频啸叫。Notch 陷波器是精准手术刀，只挖掉 260 Hz 尖峰，不影响其他频段。补充：零极点对消（内模控制），如位置环、倒立摆、磁悬浮。

**Step 1**：先用保守低增益闭环稳住，哪怕响应慢，先保证不倒。相比盲目试凑碰运气，扫频定量整定把延时和负载惯量全算进去了。若对象开环不稳，就先加保守闭环稳住再扫频反推（如位置环、倒立摆、磁悬浮）。

**实战记住两点**：扫频时要用小信号防止驱动饱和；如果相位掉得太快，说明延时限制了带宽上限，就要靠减延时或加前馈来破局。
