## 一、操作流程总结

### 1. 设备与校准

- 仪器：GW INSTEK **LCR-6200** 精密 LCR 表（10 Hz–200 kHz），配**四线开尔文夹具**；
- 测量前先做**开路、短路校准**，消除夹具和引线误差。

### 2. 仪器设置

- 功能模式：选 **Ls–Rs（串联等效电感 / 串联等效电阻）**；电机绕组属于低阻抗电感，优先用串联模式，不用 Lp 并联模式；
- 频率：**1 kHz**；测试电压：**1 V**；量程：**Auto**；测量速度：**Slow**，保证读数稳定。

### 3. 接线与读数

- 夹具夹在 **U、V 两相，W 悬空**；此时仪器读到的是 **UV 之间的线电感、线电阻**，不是 FOC 直接用的相参数；
- 示例读数：**Ls ≈ 3.99 mH，Rs ≈ 2.16 Ω**（屏幕稳定值在 4.00 mH / 2.18 Ω 附近波动）。

### 4. 线参数 → 相参数换算（星形接法）

画面给出的公式：

|量|换算|
|---|---|
|相电阻|**Rs_phase = Rs_line / 2**|
|d 轴电感|**Ld = Ls_min / 2**（取最小线电感）|
|q 轴电感|**Lq = Ls_max / 2**（取最大线电感）|

### 5. 三相一致性判断

- **UV、VW、WU 三对都要测一遍**，对比三相电感、电阻是否均衡；
- 若三相差距很大，说明电机绕组存在问题（匝间、相间或接线异常）。

## 二、完整口播文案

做 FOC 矢量控制，拿到新电机第一件事就是确认电机参数，测量定子电感和电阻。今天这条视频是我自己的操作存档，以后新电机来了忘了怎么操作，直接翻这条视频。

这台是四线开尔文测试，开路、短路校准完成。进行功能选择，这台设备可以测量电感、电容、电阻、电抗和电导等参数。

选择 **Ls-Rs 模式**，前者是串联等效电感，后者是串联等效电阻。测电机绕组属于低阻抗电感，优先选串联模式，而不是 Lp 并联模式。

频率设置 1 kHz，测试电压 1 V，档位 Auto 自动，速度 Slow，保证读数稳定，就是屏幕上现在这个界面。

现在把夹具夹在电机的 UV 两相，W 悬空。注意这个时候仪器读到的是 UV 之间的**线电感、线电阻**，不是 FOC 算法直接用的相电感、相电阻。

现在读到的 **Ls = 3.99 mH，Rs = 2.160 Ω**，这个是 UV 两相之间的线参数。

星形接法直接除以 2，就能得到 FOC 模型里面要用的单相等效参数：**Ld = Ls_min / 2，Lq = Ls_max / 2，Rs_phase = Rs_line / 2**。

三相都要测一遍，用来判断三相绕组是否均衡。如果三相差距很大，说明电机绕组有问题。

## 三、补充提醒（视频未展开的工程要点）

- **接法前提**：除以 2 是**星形（Y）接法**的结论；若是三角形（△）接法，线/相参数换算关系不同，不能照搬；
- **电感随转子位置变**：Ld、Lq 要在对应电角度（d 轴 / q 轴对齐）读取极值，转子位置不同，线电感读数会变；
- **电阻温度修正**：绕组电阻随温升明显变化，记入模型时最好注明测量时的温度；
- 这条只覆盖**绕组 L、Rs**；反电势常数 / 永磁磁链 ψf 还需要通过空载反电势或拖转测试另外获取。
