# zephyr OS的驱动


|研究内容|你要弄明白的问题|
|---|---|
|**启动流程**|从复位到内核初始化，再到应用 `main()`，经历了什么？|
|**线程与调度**|线程如何创建？优先级如何影响抢占和运行顺序？|
|**等待与唤醒**|调用 `k_sleep()` 后线程去了哪里？谁把它唤醒？|
|**上下文切换**|切换线程时保存哪些状态？线程栈起什么作用？|
|**同步与通信**|信号量、互斥锁、消息队列如何让线程协作？|
|**中断与线程**|中断如何触发线程处理？哪些操作不能放在中断里？|

## 加入 UI 界面



west build -b qemu_cortex_m 3 app -d build/app

| 部分                  | 含义                                                    |
| ------------------- | ----------------------------------------------------- |
| `west`              | Zephyr 项目的命令行管理工具                                     |
| `build`             | 执行构建                                                  |
| `-b qemu_cortex_m3` | 选择目标板，从而确定 CPU、硬件配置等                                  |
| `app`               | 应用源码目录，里面有 `CMakeLists.txt`、`prj.conf` 和 `src/main.c` |
| `-d build/app`      | 指定构建目录，存放中间文件和最终固件                                    |
