# 编译

west build -b qemu_cortex_m 3 .deps/zephyr/samples/hello_world -d build/hello_world


编译链接过程：
CMake 根据配置生成文件列表，再由 Ninja 按这个列表调用编译器、链接器。把选中的 Zephyr 源码和应用源码一起编译、链接成固件。
① CMake 决定编译哪些源码
		CMakeLists.txt 中决定要编译哪些源码

② 编译成目标文件，组织成静态库


应用 main.c       → main.c.obj → app/libapp.a
选中的内核源码    → 多个 .obj  → zephyr/kernel/libkernel.a
选中的串口驱动    → 多个 .obj  → libdrivers__serial.a

③ Ninja 把这些文件交给链接器
build.ninja 文件中列举出：
```
app/libapp.a
zephyr/libzephyr.a
zephyr/kernel/libkernel.a
ARM 架构库、SoC 库、串口驱动库等
zephyr/linker.cmd
```
