# 任务系统维护

## 日常使用

- 独立页面 [[今日任务]] 汇总今天计划、今天开始、今天截止和正在进行的任务，按优先级从高到低排列；优先级相同时按截止日期排序。有今日子任务时保留父任务归属，并采用父任务与今日子任务中较高的优先级。
- 今日页使用紧凑清单，子任务、逾期待安排及今日已完成默认折叠。可直接勾选、修改状态、进入详情，也可把逾期待办“安排今天”。
- “新增今日任务”自动填写今天的计划日期。其他已有任务可在编辑弹窗设置计划日期（`⏳ YYYY-MM-DD`）；单纯放在源文件“今日任务”标题下不会把长期积压待办全部带入今日页。
- 关注队列（Focus Queue）只显示父任务或有效子任务处于“进行中”的项目。父任务尚为待办但子任务在推进时，卡片会标注“子任务进行中”。日期临近、逾期、属于今日任务分区都不会单独触发入队；待办可在本周任务等分类查看。延期、阻塞、取消和完成的分支不会触发入队。
- 中心的“新增任务”可创建父任务，选择今日、近期或长期分区，并设置状态、优先级、开始/截止日期和下一步。默认进入今日任务；源文件缺少对应分区时会自动补齐。
- 详情页“优先级”下拉框选择后自动保存，支持最高、高、中、普通、低、最低。选择普通会移除 Tasks 优先级标记。编辑任务弹窗中也可以修改优先级。
- 卡片上的加号：添加子任务；铅笔：编辑名称、状态、截止日期和下一步；笔记图标：记录进展。
- 子任务可以在中心直接勾选。所有子任务完成后，父任务显示“待验收”，确认验收后才归档。
- 中心和详情页的父任务、子任务使用相同的彩色状态标签。点击状态标签可修改状态；勾选框只负责完成与取消完成。状态颜色：待办灰蓝、进行中蓝、延期琥珀、阻塞红、待确认紫、重要橙、完成绿、取消灰色删除线。
- 延期和阻塞任务填写原因、下次检查日期。恢复任务时，将状态改回待办或进行中。
- “每周整理”集中显示待验收、到期检查、逾期、缺少下一步及 14 天未更新的任务。
- 到期检查在任务中心显示，不会在 Obsidian 关闭时发送通知。

## 长期任务打卡

在“编辑任务”里开启“每日打卡”，并设置每周目标（1 至 7 天，默认 5 天）。英语学习已开启，每周目标为 5 天。

开启后，任务在今日页独立的“今日打卡”区域出现，不再占用普通今日任务清单。延期、阻塞、取消或已完成的任务不会出现在打卡区域。详情页可查看本周完成天数、本周时长、累计时长和最近记录。

打卡默认今天，可填写时长、完成内容、收获与问题、下一步。更改日期可补记；选择休息日可留下休息记录，休息日不计完成天数或时长。每个任务每天只保留一条记录，重复打开可修改，不会重复累计，也不会自动完成父任务或子任务。

### 完成反馈与成长

- 保存有效打卡后会出现完成提示、成长值及新解锁成就。今日页将当天已完成的习惯单独列出，保留心得摘要和正文入口。
- [[打卡成就]] 汇总全部习惯的完成记录、累计次数、投入时长和近四周足迹；可按习惯、本周、本月、全部或指定日期筛选，也能查看休息记录。
- 每个习惯每天有效完成一次获得 10 成长值，每累计 100 成长值升一级。修改内容、调整时长、关联多篇正文不会重复加分。补记归入原日期并只计一次；休息日不扣已有成长值。将错误的完成记录改成休息时，会按实际记录重新计算。
- 累计完成 1、3、7、14、30、60、100 次可解锁相应成就。总览显示整体积累，任务详情显示该习惯自己的积累，不要求连续打卡，也没有漏一天清零规则。
- 成长值直接由现有日志计算，旧记录自动计入；关闭打卡模式或将任务移出源文件后，月度日志中的历史仍可在成就页查看。读取不完整的日志会显示提示，不会自动改写或删除原文。

**文本记录是可选项，默认不勾选。** 简单任务只在打卡弹窗保存简短记录或心得即可，不创建额外正文文件。

需要详细记录时，勾选“创建或打开文本记录（可选）”，可填写文本标题，保存后打开正文。新的正文只放在用户创建的 `任务清单/对应任务/` 目录，例如 `任务清单/英语学习/2026.10.20 跟读练习.md`。优先复用现有任务文件夹，缺少对应任务目录时才创建；不会把正文放入 `daliy record`。

同一天可以关联多篇正文。勾选后可选择“新建一篇”“打开已关联文本”或“关联已有文件”。新建时可使用不同标题，并填写任务目录内的相对子目录；关联已有文件时可以选择子目录里的 Markdown 笔记。与任务同名不是要求，其他子文件夹和文件无需改动。

相同任务、日期和创建标题再次提交会复用该篇记录，不覆盖手写内容；不同标题可以新增另一篇。同名的其他笔记使用序号避让。已有正文可从下拉列表或历史入口打开，多篇正文仍只计一个打卡日。

支持 Obsidian 的相对路径、简写名称、省略 `.md`、标题锚点和别名链接；最终以解析后的实际文件位置为准。正文仍限定在 `任务清单` 内，文件名和子目录可以自行组织。解析到多个同名文件时需使用更完整的目录路径。修改心得会保留所有原有链接。

正文是普通 Markdown，不含自动摘要或子任务同步标记，可自由编写、添加图片和资料。打卡更新只更新月度简短记录，不改写正文。若正文创建失败，已保存的打卡会保留，弹窗会明确提示，可重试。

记录保存在 `daliy record/打卡记录`，每个任务每月一篇 Markdown，使用固定任务 ID 关联。改名后继续使用同月原文件，跨月自动建立新的月度记录；关闭打卡模式会保留历史。月度记录可从详情页打开。

请通过界面修改打卡块，保留 `tcc-checkin` 注释标记。自由笔记和图片可以放在记录块外，同步或修改当天记录时会保留这些内容。系统不允许预填未来日期；连续多日补记按各自日期归档、统计。

字段：`[tcc_habit:: true]` 开启打卡，`[tcc_habit_goal:: 5]` 设置每周目标。

## 创建任务记录

任务详情右上角的“创建任务记录”会在库根目录的 `daliy record` 创建并打开笔记，默认文件名为 `日期 任务名.md`。可选择“工作记录”“故障排查”或“仅生成标题”，每个已有子任务都会获得对应标题，多级子任务标题保留所属路径。

从子任务详情创建记录时，名称、文件名及新笔记正文标题带上父任务层级，例如 `2026.10.30 boot+信息安全 - boot当前的代码了解.md`。多级任务使用 `祖先任务 - 父任务 - 子任务`；自定义记录名称也保留父任务前缀。记录仍绑定当前子任务的固定 ID，摘要中可看到所属任务。已有笔记不自动改名或改写正文标题。

同日、同名、同一任务再次创建时打开已有记录；遇到其他同名笔记时使用序号，不会覆盖。创建的记录会自动出现在详情页“关联文档”，支持点击或键盘打开。

新记录包含固定任务关联、当前状态、优先级、日期、下一步、子任务完成数和层级摘要。`task_progress` 表示复选框完成度；原有手写 `progress` 仍作为工作进度记录，自动摘要不会反过来覆盖任务中心的工作进度。

打开任务视图后，本次 Obsidian 会话会监听任务源的变化并更新这些新记录；重启后再次打开任务中心、详情或复习页也会补同步。旧历史笔记不参与自动改写。

带 `tcc:task-summary` 标记的摘要和 `tcc:subtask` 标记内的标题由系统维护。写在模板正文中的过程、结论、截图和自定义属性会保留。新增子任务会补上模板；删除子任务不会删除它已有的历史正文。保留这些 HTML 注释标记，标记受损时系统会暂停该记录的同步并提示。

## 数据与标识

`工作任务.md` 仍是任务源，支持手动编辑和嵌套子任务。

打开中心、详情或复习页时，系统会为没有 ID 的任务添加 Obsidian 块标识，例如 `^tcc-...`。移动或改名时保留末尾 ID；复制为新任务时移除副本 ID，刷新后会自动生成新 ID。

`_task-index.json` 自动保存任务旧名称、位置和最近更新记录。应随笔记库一起同步，保留改名后的历史关联。首次启用时开始记录“多久未更新”，打开页面本身不会重置这个时间。

已有工作记录继续按关联任务名称查找。通过中心改名后，旧名称仍能关联。文档也可用 `related_task_id` 指定固定身份，其值为 `tcc:` 加任务末尾的块 ID（不含 `^`）；多个任务使用 YAML 列表。

手动编辑时可使用以下字段，界面会隐藏它们：

| 字段 | 含义 |
| --- | --- |
| `[tcc_next:: 确认接口后执行台架测试]` | 下一步行动 |
| `[tcc_reason:: 等待硬件]` | 延期或阻塞原因 |
| `[tcc_check:: 2026-09-23]` | 下次检查日期 |
| `[tcc_blocked:: true]` | 阻塞；底层复选框使用进行中状态 |

延期继续使用 `[>]`。完成继续使用 `[x]` 和完成日期。子任务清单、进展日志与复习记录都保存在父任务下面。

## 代码维护

- `tasks-core.js`：固定 ID、原子写回、进度、维护表单、整理规则和样式同步。
- `task-records.js`：记录命名、模板、属性同步、子任务标题和正文保护。
- `今日任务.md` 与 `tasks-today.js`：今日清单、日期筛选、父子归属和优先级排序；与中心共用任务源及编辑操作。
- `task-checkins.js`：每日打卡、休息日、本周与累计统计、月度日志及历史编辑。
- `打卡成就.md`：跨习惯完成记录、日期筛选、成长等级、积累徽章和近四周足迹。
- `obsidian_tasks_command_center.md`：任务分组与中心布局。
- `任务详情.md`：详情、子任务树与历史时间轴。
- `复习时间轴.md`：复习计划视图。
- `tasks-command-center.css`：唯一需要编辑的样式源。打开任一任务视图时，会同步到当前库配置目录的 `snippets/tasks-command-center.css`。

修改完成后重新打开视图。不要分别修改两份 CSS，片段副本会被样式源覆盖。
