如何基于IAR编译器添加编译时间戳和软件版本号？

开心果 Need Car · 2025-04-25T06:32:00+08:00 · 微信原文

软件的开发过程中，需要经常编译不同版本的软件。有时为了测试某个功能，需要临时添加一个版本；有时为了查找bug，需要不断编译和调试...如果编译的版本多了，可能自己都会混淆。所以，为了更好的识别软件的版本信息，最好的方式就是让工具“操心”这个容易忘记的事情。怎么做呢？让编译器每次编译时，自动添加软件编译的时间戳。
提示：IAR软件版本9.40.1

1、获取时间戳和软件版本方式

关于软件版本，可以使用宏等方式自行定义，对于编译软件的时间和日期，可以分别使用宏__TIME__和__DATE__。使用这两个宏，需要包含stdio.h头文件。
设置软件的编译时间戳和版本号，目的是为了识别版本，所以，就需要预留对外的接口，供外部调用。
本文编写的hsm_firmware_version_info.h文件内容如下：
/** * \file hsm_firmware_version_info.h * \brief This file contains the version information of the HSM firmware. * */#ifndef HSM_FIRMWARE_VERSION_INFO_H_#define HSM_FIRMWARE_VERSION_INFO_H_
#include <stdio.h>#include "zf_common_headfile.h"
#define VERSION "1.0.3"
extern void Get_HSMFirmwareVersionInfo(uint8* HSMInfoPtr);
#endif /* HSM_FIRMWARE_VERSION_INFO_H_ */
本文编写的hsm_firmware_version_info.c文件内容如下：
#include "HSMFirmwareVersionInfo.h"
const uint8 *HSMBuildInfo = "HSM Firmware Version: " VERSION " " __DATE__ " " __TIME__;
void Get_HSMFirmwareVersionInfo(uint8* HSMInfoPtr){    memcpy(HSMInfoPtr, HSMBuildInfo, strlen(HSMBuildInfo));}
将如上的两个文件加载到软件工程中。
外部调用示例：
uint8 HSMInfo[50] = {0x00};
Get_HSMFirmwareVersionInfo(HSMInfo);

2、如何实现编译软件时的时间戳更新？

软件开发过程中，一般使用增量编译的方式加速软件编译速度。但是，如果时间戳的源文件没有修改，那么，编译器会忽略该文件，不做编译。如此，会带来一个问题：编译后，时间戳没有更新。那么，使用全量编译（rebuild All）可以吗？采用全量重编的方案确实可以，但是，这也意味着编译时间增加。那么，能不能只对特定源文件编译呢？答：可以。
