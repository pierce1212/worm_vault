1、将常量放入指定PFlash地址空间的操作
如果要将常量放入指定的PFlash位置，主要包括两步：修改链接文件、在源文件中将目标常量设定到目标段。
（一）在链接文件（*.lsl）中开辟指定的PFlash段（Section）
链接文件主要用来告知链接器（Linker）
，应该如何分配变量和函数的地址空间。
具体操作如下所示：
#
define
HSM_MYCONSTANT_ADDRESS   0x8001B000
......
section_layout :ARM:linear
{
group
( ordered, run_addr=HSM_MYCONSTANT_ADDRESS )
{
select
".myConstant"
;
}
}
......
在Section中定义一个Group，且指定起始的PFlash地址为0x8001B000，将目标段（eg：.myConstant）放入该Group中。
注意：
Section_layout指定了ARM内核的内存空间，如果是其他的Core架构，引用的内存空间可能不同，注意区别。
