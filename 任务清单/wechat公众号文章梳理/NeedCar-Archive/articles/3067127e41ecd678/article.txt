搭建过项目工程的小伙伴，对于用户启动地址设置应该不陌生。如果有祖传的项目Base，且Memory Layout未有改动，可以直接移植，工作相对会轻松一些。如果项目使用的芯片类型有变化，或者
Memory Layout重新划分，那么，启动地址很可能需要重新设置，否则，程序将无法按照预期运行。如果要修改用户启动地址，如何操作呢？本文，基于TC3xx，聊一聊用户启动地址设置的问题。

（一）链接文件修改
不管使用何种编译器，
链接文件
必不可少，因为它约束着程序、变量存放的位置。对于启动地址也不例外，也需要在链接文件中指定，以便于程序入口地址可以被分配到用户指定的位置，这样，CPU就可以准确的获取第一条指令位置。
链接文件中，用户可以
自定义
程序
启动地址
（eg：0xA0020000），同时，将该启动地址赋给复位标号（RESET），即：每次程序复位时，复位到程序的入口位置，如下所示：
......

0
xA0020000;
LCF_STARTPTR_NC_CPU1
=

= LCF_STARTPTR_NC_CPU0;
......
将
启动程序
设置到
启动地址开始的位置
，对应段（Sections）的设置如下所示：
/*Fixed memory Allocations for _START*/
CORE_ID = GLOBAL;

.start_tc0 (LCF_STARTPTR_NC_CPU0) : FLAGS(rxl) {KEEP (*(.start));}> pfls0_nc
......

Memory Layout的设计
，因项目不同而有所不同，这个大家可以根据实际情况自行设定。
