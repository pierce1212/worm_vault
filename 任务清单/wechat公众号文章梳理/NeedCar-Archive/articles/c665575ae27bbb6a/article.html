如何基于PLS UDE调试他人的镜像文件（*.out/*.elf）？

开心果 Need Car · 2026-01-12T06:20:00+08:00 · 微信原文

从事软件开发的小伙伴知道，一个大型软件工程，从来不是一个人的单打独斗，而是需要多人的协作开发。既然是协作，就可能遇到这样一个场景：工程师A需要工程师B协助排查问题，工程师A将编译后的调试文件（eg：*.elf、*.out）给到工程师B，工程师B基于收到的*.elf/*.out+本地源文件进行问题调试，只有*.elf/*.out这样的文件，该如何调试呢？
在前文《别人的*.elf文件，该如何使用Lauterbach进行白盒调试？》讨论过基于Lauterbach的操作，那么，基于PLS UDE又该如何操作呢？

1.基于PLS UDE的源文件路径替换

比如，原始文件编译路径识别为D:\A\SRC\
注意：*.hex或者*.sre等文件没有对应的Symbol，无法用于调试。

（一）打开路径管理窗口

在菜单栏依次选择：Config → Debug Server Configuration → View Server → Source Code → Path Management

如下所示：

（二）设置路径映射

设置操作如下所示：

注意：“Replacements/Excludes”中替换文件路径和本地源文件路径使用\，不是/。

原路径（Original path）：*.elf/*.out文件中记录的源码目录路径，可以在 UDE 左侧文件结构中查看到这些路径。

现路径（Current path）：本地实际存放源代码的路径。

如果无法打开源码，还需检查：路径映射是否生效、源代码是否被加密（例如压缩或加密存档）
