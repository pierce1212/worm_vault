EB配置实践：STM配置及使用

开心果 Need Car · 2024-01-02T07:19:00+08:00 · 微信原文

搞MCAL开发的小伙伴，对EB Tresos的使用，应该不陌生。我们知道，每家芯片厂商不光是卖芯片，他们也会将对应芯片的MCAL开发好，配套对应型号的芯片。所以，一般来说，商用MCAL需要找芯片原厂或者指定的代理商购买。但是，对应MCAL的配置上位机，不一定原厂提供，比如本文要聊的EB Tresos软件，EB Tresos由Elektrobit(简称EB)开发的一款用于开发汽车ECU软件的工具。

本文，主要讨论基于EB Tresos的STM配置及使用。

本文不具体讨论EB Tresos的安装。EB Tresos安装以后，在安装路径下会找到基础的软件使用手册及文档，同时，解压对应芯片版本的Package。本文，基于工程自带的Demo工程讨论。

2、STM配置

配置STM，我们需要先搞清楚一个问题：为什么使用STM？比如本文：基于STM，设置一个5ms定时器，以中断方式触发。
（一）STM配置操作
如果想要配置的STM按照预期目标工作，那么就需要先搞清楚配置STM所关联的对象。如果STM工作，需要配置MCU模块，即：MCU配置STM所需要的时钟，以及MCU所关联的STM。

void core0_main (void){  unsigned short cpuWdtPassword;  unsigned short safetyWdtPassword;
  ENABLE();  /*  * !!WATCHDOG0 AND SAFETY WATCHDOG ARE DISABLED HERE!!  * Enable the watchdog in the demo if it is required and also service the watchdog periodically  * */  cpuWdtPassword = Ifx_Ssw_getCpuWatchdogPassword(&MODULE_SCU.WDTCPU[0]);  safetyWdtPassword = Ifx_Ssw_getSafetyWatchdogPassword();  Ifx_Ssw_disableCpuWatchdog(&MODULE_SCU.WDTCPU[0], cpuWdtPassword);  Ifx_Ssw_disableSafetyWatchdog(safetyWdtPassword);
  /* MCU initializations */  Mcu_Init(&Mcu_Config);  Mcu_InitClock(0U);  while(Mcu_GetPllStatus() != MCU_PLL_LOCKED);  Mcu_DistributePllClock();    /* Configure Interrupt priority */  IrqStm_Init();  SRC_STM0SR0.B.SRE = 1U;  /*Enable Stm interrupt*/  Stm_EnableModule(STM_0);
  /*Enable interrupt and call-back */  Stm_EnableAlarm(STM_0, STM_CMP0_USED, STM_CMP_MODE_CONTINUOUS , STM_500000_TICKS_5MS, Stm_CallbackFunction);
  while (1)  {    if (TRUE == TaskFlag_5ms)    {        TaskFlag_5ms = FALSE;        TaskCnt++;    }  }}
