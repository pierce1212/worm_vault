DDS开发笔记：基于Ubuntu20.4跑micro-xrce-dds（一）

开心果 Need Car · 2022-05-17T18:37:00+08:00 · 微信原文

想学习DDS(Data Distribution Service)，但是又没有配套的商用软/硬件，莫慌。虚拟机里跑开源DDS，一样可以玩DDS，本文给大家分享一下自己学习DDS过程中的一些总结。

开始学习之前，先了解一下用到软/硬件环境，如下所示：

  1. Micro XRCE-DDS Gen工具，将*.idl文件配置信息生成对应目标代码；
  2. 传输层可以使用TCP、UDP、Serial、Custom中的一种；

  3. 在Client侧，使用MicroCDR库对数据进行序列化/反序列化操作；而在Agent侧，需要用FastCDR对数据进行序列化/反序列化操作。

  4. 本文安装环境：虚拟机：VBox ，Ubuntu版本：20.4

1
运行Agent

运行Agnet之前，需要先安装Agent，并且编译对应的Code，具体指令如下所示：

$ git clone https://github.com/eProsima/Micro-XRCE-DDS-Agent.git$ cd Micro-XRCE-DDS-Agent$ mkdir build && cd build$ cmake ..$ make$ sudo make install

此示例中，Client-Agent通过 UDP 通信，使用端口 2019。

$ cd /usr/local/bin && MicroXRCEAgent udp4 -p 2019

注意：需要先运行Agent进程，在运行Publisher/Subscriber进程，否则Session无法创建。

clone代码时遇到的问题

Error01：OpenSSL SSL_read: Connection was aborted,  errno 10053，如下所示：

原因：Git默认限制推送的大小
修改策略：运行命令更改限制大小即可，命令如下所示。
git config --global http.postBuffer 524288000

3
Micro XRCE-DDS Gen tool安装
Micro XRCE-DDS的使用，需要配套对应的*.idl生成源文件，Micro XRCE-DDS-Gen tool的安装步骤如下所示：
$ sudo apt install git openjdk-8-jdk gradle$ git clone https://github.com/eProsima/Micro-XRCE-DDS-Gen.git$ cd Micro-XRCE-DDS-Gen$ git submodule init$ git submodule update$ gradle build -Dbranch=v1.2.5
查看Micro XRCE-DDS-Gen tool的使用帮助，命令如下所示：
./scripts/microxrceddsgen -help
