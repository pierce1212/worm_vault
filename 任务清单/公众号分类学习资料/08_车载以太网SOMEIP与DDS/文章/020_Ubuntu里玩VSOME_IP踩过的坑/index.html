Ubuntu里玩VSOME/IP踩过的坑

开心果 Need Car · 2022-01-08T11:19:00+08:00 · 微信原文

最近在搞SOME/IP，在没有商用软硬件的条件下，只能自力更生，在VBox中玩开源的VSOME/IP。在玩VSOME/IP过程中，配置环境踩了一堆的坑，本文分享一下自己遇到的那些坑以及解决方法。

资源说明

先说明一下使用的资源环境:
  • 虚拟机：VBox
  • Ubuntu:18.04
  • 开发板：英飞凌T507-C

  • 语言：C++

VBox和开发板均使用VSOME/IP，如果没有开发板，也可以多设置两个VBox,每个VBox里使用VSOME/IP。
VSOME/IP开源代码我是在gitee上下载，具体链接：
https://search.gitee.com/?skin=rec&type=repository&q=LakeyLee1987%20%2F%20vsomeip
具体如下所示，下载第一个即可。


换源

什么是源？可以将源看作是一个服务器站点，在这里可以下载和更新软件。
为什么需要源？当我们在虚拟机中安装好Ubuntu操作系统时，需要安装我们所需要的软件，而这些软件的下载需要从源获取。
参考：https://blog.csdn.net/SAKURASANN/article/details/104257996
到底选择哪个源好一些呢？国内的我使用过阿里源和华为源。但是具体在切换的时候哪个能成功还真不好说，一般我的做法是先尝试一下阿里源，不成功在尝试华为源，哪个安装成功用哪个。
参考：https://blog.csdn.net/qq_35451572/article/details/79516563
提示：如下指令一定要运行。
//更新源sudo apt-get update//更新软件sudo apt-get upgrade

libboost安装

使用开源的VSOME/IP需要安装libboost，安装过程中，我按照README安装踩了坑。

坑点：README中提示安装libboost-system1.55-dev、libboost-thread1.55-dev、libboost-log1.55-dev，使用其指令，安装一直失败。
提示安装指令如下所示：
sudo apt-get install libboost-system1.55-dev libboost-thread1.55-dev libboost-log1.55-dev

使用说明的方法行不通，安装要求Boost >= 1.55，那索性直接安装最新的版本。

参考：https://blog.csdn.net/qq_41854911/article/details/119454212

使用了参考中的"最佳方法"，解决问题。

Error：Configuration module could not be loaded!


在运行VSOME/IP的server进程时遇到了如下错误：
forlinx@forlinx:~/Documents/vsomeip_master/build/examples$ env VSOMEIP_CONFIGURATION=../../config/vsomeip-udp-service.json VSOMEIP_APPLICATION_NAME=service-sample ./response-sampleConfiguration module could not be loaded!
参考：https://github.com/COVESA/vsomeip/issues/253
这里需要说一下，参考没有解决我的问题，如果你遇到类似问题，可以先尝试参考给的解决方案。
我的问题是默认搜索路径下没有找到共享库：libvsomeip3.so。因为libvsomeip3是VSOME/IP生成的，安装时没有放到默认搜索路径下，需要手动设置。
（1）如何查找目标库的位置？
答：使用如下指令查找
 //查找libvsomeip3库位置sudo find / -iname "*libvsomeip3*" 

运行结果：

可以看出libvsomeip3.so所在的路径是：/home/forlinx/Documents/vsomeip_master/build
（2）如何将模块/共享库添加到搜索路径？
参考：

https://blog.csdn.net/cainiao2013/article/details/88926106?utm_medium=distribute.pc_relevant.none-task-blog-2~default~baidujs_baidulandingword~default-1.no_search_link&spm=1001.2101.3001.4242.2&utm_relevant_index=4

本文使用了参考的第一种方法，将动态链接库所在的路径添加到/etc/ld.so.conf中，如下所示：
include /etc/ld.so.conf.d/*.conf/home/forlinx/Documents/vsomeip_master/build

最后运行ldconfig，更新一下搜索路径：

sudo ldconfig
