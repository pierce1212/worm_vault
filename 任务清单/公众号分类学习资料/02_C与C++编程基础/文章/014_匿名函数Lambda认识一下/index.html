匿名函数Lambda认识一下

开心果 Need Car · 2021-12-22T20:30:00+08:00 · 微信原文

在C++11中有一种匿名函数：Lambda。之所以出现该函数，是因为“懒人”太多（比如我），不想给函数起名字。不仅在C++中有lambda函数，在python等语言中也有。学会一个，其它语言也就都能理解了，具体使用大家可以根据需求自行查阅和选用，本文聊聊C++中的Lambda函数。

Lambda定义

Lambda定义：

[外部参数说明符] (参数列表) -> 返回值类型

{

   函数体

}

1.外部参数说明符

外部参数说明符主要有=和&，也可以为空。=可以理解为按值传递，按值传递就是传入什么参数，用什么参数，不能修改。&可以理解为按引用传递，按照引用传递可以修改该参数，因为是传入参数的地址，所以可以找到地址修改参数值。

举例：

[Arg_1, &Arg_2](int Arg_3)->int{...}/* 等价与 */[=, &Arg_2](int Arg_3)->int{...}

对外部变量Arg_1和Arg2进行限定。限定Arg_1不能修改，Arg_2可以修改，同时传入参数Arg_3。

2.参数列表

这部分和普通函数没什么区别，根据功能定义传入参数个数和类型或者不传参数。

如果没有被mutable修饰且传入参数为空，参数列表可以省略，即()可以省略。

示例：

Auto lambdaH = []{...};

3.返回值类型

表示Lambda函数的返回值类型，也可以没有返回值。

4.函数体

具体的函数功能实现部分，不能省略。

使用示例

示例1

#include <iostream>using namespace std;
int main(){    /* 定义外部变量Arg_1、Arg_2 */    int  Arg_1 = 0x10, Arg_2 = 0x00;    /* 限定外部变量Arg_2可以修改，其余外部变量     * 不能修改，即Arg_1不能修改，传入参数Arg_3 */    auto lambdaHandle = [=, &Arg_2](int Arg_3)->int{        /* 修改外部变量Arg_2*/        Arg_2 = 0x20;        return (Arg_1 + Arg_2 + Arg_3);    };        /* 调用lambdaHandle函数 */    int sum = lambdaHandle(0x30);    cout<<"sum = 0x" << std::hex << sum << endl;    getchar();    return 0;}

运行结果：

sum = 0x60

示例2

在C++中，万物皆对象，Lambda函数也不例外，也是一个对象，可以使用Auto类型保存和使用。这样做类似于将Lambda函数进行了封装，使用更方便。

#include <iostream>using namespace std;
auto lambdaHandle = [](int Arg_1, int Arg_2, int Arg_3)->int{        return (Arg_1 + Arg_2 + Arg_3);};int main(){    /* call lambdaHandle */    int sum  = lambdaHandle(0x10, 0x20, 0x30);    cout<<"sum = 0x" << std::hex << sum << endl;    getchar();    return 0;}

运行结果：

sum = 0x60
如果Lambda函数没有使用外部参数，可以将lambda函数对象保存给函数指针，使用示例如下所示：
#include <iostream>using namespace std;
int (*lambdaPtrFuc)(int, int, int) = [](int Arg_1, int Arg_2, int Arg_3)->int{        return (Arg_1 + Arg_2 + Arg_3);};
int main(){    /* call lambdaPtrFuc */    int sum  = lambdaPtrFuc(0x10, 0x20, 0x30);    cout<<"sum = 0x" << std::hex << sum << endl;    getchar();    return 0;}

运行结果：

sum = 0x60
