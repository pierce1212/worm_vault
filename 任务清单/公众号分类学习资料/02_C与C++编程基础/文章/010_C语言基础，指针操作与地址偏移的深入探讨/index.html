C语言基础，指针操作与地址偏移的深入探讨

开心果 Need Car · 2024-12-27T06:57:00+08:00 · 微信原文

问题：指针+操作，地址到底偏移了多少？这个问题，其实就是一个C语言的基本功问题。但是，我这也有栽跟头的时候，以此写一个教训，也给大家一个提示。
我们知道，指针的本质就是一个内存地址，当指针进行+操作时，地址偏移多少取决于指针的类型。
举例如下：
#include <stdio.h>#include <stdint.h>
uint8_t Arg_A[12] = {0x00};uint16_t Arg_B[12] = {0x00};uint32_t Arg_C[12] = {0x00};
int main(){    printf("Arg_A Address = %p\n", Arg_A);    printf("Arg_A Address add 2 = %p\n\n", (Arg_A+2));        printf("Arg_B Address = %p\n", Arg_B);    printf("Arg_B Address add 2 = %p\n\n", (Arg_B+2));        printf("Arg_C Address = %p\n", Arg_C);    printf("Arg_C Address add 2 = %p\n\n", (Arg_C+2));
    return 0;}
运行结果，如下所示：
Arg_A Address = 0x56aca32d9040Arg_A Address add 2 = 0x56aca32d9042
Arg_B Address = 0x56aca32d9050Arg_B Address add 2 = 0x56aca32d9054
Arg_C Address = 0x56aca32d9080Arg_C Address add 2 = 0x56aca32d9088
如上示例可以清楚表明：指针进行+操作时，偏移地址的多少与最初定义指针类型有关，eg：uint8* p，p+2偏移两个字节，uint16* p，p+2偏移四个字节。
当然，实际的工程中，指针的使用远不止这样简单，定义一个数据模块或者数据对象时，一般会使用多种数据类型。
稍微改造一下如上程序，示意如下：
#include <stdio.h>#include <stdint.h>
typedef struct{    uint8_t Arg_A;    uint16_t Arg_B;    uint32_t Arg_C;    uint32_t* Arg_D;}str_Type;
str_Type Arg_Test = {0x00};
int main(){        printf("Arg_Test Address = %p\n", &Arg_Test);    printf("Arg_Test Address add 2 = %p\n\n", (&Arg_Test+2));
    return 0;}
运行结果，如下所示：
Arg_Test Address = 0x5e9e5c0e1020Arg_Test Address add 2 = 0x5e9e5c0e1040

&Arg_Test+2为什么偏移了32个字节，这是因为我的机器默认进行了4字节对齐，即：str_Type结构体中的每个元素默认占用4byte，所以&Arg_Test每次自增就会偏移16byte。

即便是这样一个基础，在编写代码时，偶尔也会犯糊涂，过于想当然了（认为地址产生了 2 字节的偏移），愿与诸君共同勉励。
