# E 2 E
## Profile 1 A/Profile 5 不同的算法区别是什么
**Profile 1 A 和 Profile 5 的主要区别是：<mark style="background: #FF5582A6;">CRC 算法不同、计数器位数不同，以及 Data ID 参与 CRC 的位置不同。** 不能只换一个多项式就完成切换。</mark>

| 比较项              | Profile 1A               | Profile 5         |
| ---------------- | ------------------------ | ----------------- |
| CRC 长度           | **8 位，1 字节**             | **16 位，2 字节**     |
| CRC 多项式          | **`0x1D`**               | **`0x1021`**      |
| CRC 初始值¹         | `0x00`                   | `0xFFFF`          |
| CRC 最终异或值¹       | `0x00`                   | `0x0000`          |
| 输入/输出位反转         | 均不反转                     | 均不反转              |
| 滚动计数器            | **4 位**                  | **8 位**           |
| 计数循环             | `0 → … → 14 → 0`，跳过 `15` | `0 → … → 255 → 0` |
| Data ID          | 16 位，低字节先算               | 16 位，低字节先算        |
| **Data ID 计算位置** | **在报文数据之前**              | **在报文数据之后**       |
| CRC 字段本身         | 不参与计算                    | 不参与计算             |

6 信号组设计 Signal Group Design

安全相关信号只能通过采用特定 E 2 E profile 保护的信号组传输。
被保护的信号组应包含安全相关信号和与其一致性相关的信号。  备注:在要求保证数据一致性的情况下,安全相关信号和非安全相关信号组合而成的信 号组是可以接受的
建议受保护信号组中的安全相关信号应当有无效值。
每个受保护的信号组应有一个特定的 Data ID,该 Data ID 由网络专业统一管理并分配。
