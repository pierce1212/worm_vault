```
u8Instance   = 1                  → FlexCAN1
event        = FLEXCAN_EVENT_BUSOFF
u32ErrStatus = 0x00204036


```

| 字段        | 值     | 含义              |
| --------- | ----- | --------------- |
| `BIT0ERR` | **1** | 发送显性位，回读却是隐性位   |
| `BOFFINT` | **1** | 发生 Bus-Off 事件   |
| `FLTCONF` | **3** | 硬件处于 Bus-Off 状态 |
| `ERRINT`  | **1** | 有通信错误事件         |
| `ERROVR`  | **1** | 错误标志尚未清除时又发生错误  |
| `ACKERR`  | **0** | 这份快照未记录 ACK 错误  |


| 函数                                 | 主要处理什么               | 第三个参数                    |
| ---------------------------------- | -------------------- | ------------------------ |
| `Can_43_FLEXCAN_CommonIrqCallback` | 报文接收完成、发送完成等消息缓冲区事件  | `u32buffIdx`：缓冲区索引       |
| `Can_43_FLEXCAN_ErrorIrqCallback`  | Bus-Off、通信错误、错误警告等事件 | `u32ErrStatus`：错误状态寄存器快照 |


调试器接收到报文之后，才会进入 Can _43_ FLEXCAN_CommonIrqCallback  ，如果有错误，进入 Can _43_ FLEXCAN_ErrorIrqCallback
