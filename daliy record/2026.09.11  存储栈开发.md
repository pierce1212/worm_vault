## 存储流程

```
NvM             管理需要保存的数据块
 ↓
MemIf           提供统一接口
 ↓
Fee             用 Flash 模拟 EEPROM
 ↓
MemAcc          管理地址和访问请求
 ↓
Mem_43_INFLS    驱动内部 Flash 硬件
 ↓
Data Flash
```
<mark style="background: #FF5582A6;">Fee 实际使用 S 001～S 010，而 MCAL 当前只覆盖 S 000～S 009</mark>

|0x10000000|0x1003FFFF|128|Data flash (Block 4)|non-cacheable|

**32K324 的 DFlash 位于 Flash Block 4，总容量 128 KiB，地址为 `0x10000000～0x1001FFFF`，分成 16 个 sector，每个 8 KiB（`0x2000` 字节）。** 最小擦除单位是一个 sector。

|                          |         |                                            |
