# 14服务NRC故障排查

`Dem_NvmGetStatus()` 获取的是 **block 最近一次 NvM 操作的结果**。真正的故障判断在此前的异步读写过程中完成，查询函数只读取已经保存在 RAM 中的状态。



## 故障是从哪里来的？

NvM → MemIf → Fee → MemAcc → Mem _43_ INFLS → C 40_Ip → Flash 硬件

| 来源             | 底层如何判断                                      |
| -------------- | ------------------------------------------- |
| Flash 硬件操作失败   | C40 驱动读取 Flash 状态寄存器，判断读写错误、擦写失败、超时及 ECC 状态 |
| block 数据无效或不完整 | Fee 检查是否存在有效副本、失效标志及数据一致性                   |
|                |                                             |


> [!NOTE] 如何判断
> if ((MCRS & DONE_MASK) == 0)
>     // 操作未完成；开启超时监督时还会判断超时
> else
> {
>     flags = MCRS & (PEG_MASK | PEP_MASK | PES_MASK);
>     // 仅 PEG=1、PEP/PES=0 时判定成功，否则失败
> }
> 读取 Flash 的 MCRS 寄存器
