## 硬件原理
![](assets/2026.07.02%20奇瑞休眠唤醒问题--唤醒报文异常/file-20260702171007049.png)
这张图的电机驱动部分可以按“有刷直流电机单向驱动 + 主动续流 + 电流采样”理解。

**1. 功率主回路**

电机是两线制，接口是 `M201`：

- `M+`
- `M-`

主驱动电流路径大致是：

```
KL30 / MOTOR_HSD
  -> Q202 高边 MOS
  -> M+
  -> 电机
  -> M-
  -> Q205 低边 MOS
  -> R221 1mΩ 采样电阻
  -> GND
```

所以 `Q202` 是高边开关，`Q205` 是低边开关。它们同时导通时，电机得电运行。

**2. Q 203 是续流/制动 MOS**

`Q203` 接在 `M+` 和 `M-` 之间，不是普通低边管。它导通时相当于把电机两端短接，用于：

- PWM 关断期间给电机电感电流提供续流通道；
- 降低体二极管续流损耗；
- 实现动态制动，让电机电流更快衰减。

注意控制时序：`Q202 + Q205 + Q203` 不能同时导通，否则会形成：

```
MOTOR_HSD -> Q202 -> Q203 -> Q205 -> R221 -> GND
```

这就是直通短路，必须靠驱动逻辑加互锁/死区避免。

**3. U 204 B 是门极驱动相关芯片**

左侧几个引脚和 MOS 驱动有关：

- `PD_D / PD_G / PD_S`：对应高边 MOS `Q202` 的漏极、栅极、源极驱动/检测。
- `VBOOT`：高边 N-MOS 需要栅极电压高于源极，`C211` 是 bootstrap/泵电容。
- `FRW_G`：驱动续流 MOS `Q203`。
- `MTG_LS`：低边 MOS `Q205` 的栅极控制信号，图中从右侧网络引入，可能来自 MCU 或另一驱动通道。

`R202/R203/R211/R214` 这类电阻是栅极电阻，用于限制开关速度、抑制 EMI 和振铃。`ZD1/ZD2/ZD3` 是栅源钳位，保护 MOS 的 `Vgs` 不超过安全范围。`R206/R212/R217` 是栅源下拉，防止驱动悬空时 MOS 误导通。

**4. 电流采样**

`R221 = 1mΩ` 是低边采样电阻。电机电流经过它时产生小电压：

```
Vshunt = I_motor * 0.001Ω
```

后面 `U203` 是运放/电流检测放大器，把这个小电压放大后输出到 `C50`，应该接 MCU ADC。

图上红字已经给了设计计算：

```
Ipeak = 110A
Vout = 110 * 0.001 * 22 = 2.42V
```

也就是放大倍数约 22 倍。110 A 峰值时，采样电阻上只有 110 mV，放大后约 2.42 V，适合 ADC 采样。

**5. 电源和抗干扰**

`C202 330uF` 是母线大电容，吸收电机启动、PWM 和续流带来的电流冲击。`C203 100nF` 是高频去耦。电机这种感性负载会产生很强尖峰，所以这里的栅极钳位、肖特基二极管、RC 滤波和大电容都很关键。

总体来说，这不是完整可反转 H 桥，而是单方向有刷电机驱动：`Q202/Q205` 负责给电机供电，`Q203` 负责主动续流/制动，`R221 + U203` 负责电流检测。
