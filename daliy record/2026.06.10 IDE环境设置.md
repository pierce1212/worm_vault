# gcc 编译

  NXP Embedded GCC 10.2 Compiler Tools for ARM v 7，Windows，build 1803

https://www.nxp.com/webapp/Download?colCode=NXP-GCC-10-2-COMPILER-TOOLS-ARM-V7-INSTALLER-WIN&appType=license&location=null

MSYS 2 是一套运行在 Windows 上的类 Unix 构建环境
工程依赖的不只是 `make.exe`，还依赖一整套 Unix 工具时,就需要安装，先提前安装好。

| 方案                           | 是否可行                           |
| ---------------------------- | ------------------------------ |
| GnuWin 32 Make 3.81 单独使用     | 基本不可行，缺少 `cygpath`、`sh` 等配套工具  |
| MSYS 2 的 `/usr/bin/make.exe` | 当前工程预期方案，推荐                    |
| 修改 Makefile 适配 Windows 原生命令  | 理论可行，但需要系统性修改和测试               |
| Git Bash + GNU Make          | 可能适配，但仍要处理 `cygpath`、工具版本和路径语义 |
|                              |                                |




环境变量：

C:\msys 64\usr\bin
目的是让 PowerShell 优先找到 MSYS 2 版本的 `make`、`sh`、`cygpath`、`sed` 等工具，而不是旧的 GnuWin 32 Make。


变量名：GCCPATH_CORTEXM 7
变量值：D:\Compiler\Gcc_v 10.2\gcc-10.2-arm 32-eabi\bin
