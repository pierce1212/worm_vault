# toolchains

- IDE：STM 32 CubeIDE
- 编译器：GNU Arm Embedded GCC
- 工具链前缀：`arm-none-eabi-`
- 目标芯片：STM 32 H 743 IITx（Cortex-M 7）
- 浮点配置：硬件浮点，`FPv5-D16`，Hard ABI
- 汇编器：GNU Assembler
- 链接器：GNU Linker


STM 32 CubeIDE for Visual Studio Code

- [ ] GDB 调试工具

- [ ] STM 32 芯片支持包

- [ ] 外设寄存器查看器
