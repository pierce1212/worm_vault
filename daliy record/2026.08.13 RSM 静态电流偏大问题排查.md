# 硬件误区
![](assets/2026.08.13%20RSM%20静态电流偏大问题排查/file-20260813143656885.png)

RTC_INT 为高阻态的时候，TP 334 并不是 上拉 5 V 的电压
这部分电路把 RTC 的开漏 `/INT` 信号转换成 TP 331 上的推挽/反相信号。

器件关系：

```
Q303 = BC807，PNP
Q305 = BC817，NPN

两个基极（Pin 1）共同连接RTC_INT/TP334
两个集电极（Pin 3）共同连接TP331
```

## 1. RTC_INT 进入高阻态

当写入：

```
Control Register 0x0F = 0x40
UIE = TIE = AIE = 0
```

U 305 不再把 `RTC_INT` 拉低，相当于从该节点断开。

此时电流路径主要是：

```
V_5V_RTC
   │
 R325 47kΩ
   │
 TP334 / RTC_INT
   │
 Q305基极
   │
 Q305发射极
   │
  GND
```

Q 305 的基极—发射极像二极管一样导通，所以 TP 334 不会升到 5 V，而是被钳位在大约：

```
TP334 ≈ 0.6～0.8 V
```

R 325 电流大约为：

```
I_R325 = (5 V - 0.7 V) / 47 kΩ
       ≈ 91 μA
```

这约 91 μA 主要作为 Q 305 的基极电流，使 Q 305 导通。

Q 305 导通后，TP 331 的电流路径是：

```
后级电源/信号
     │
   R326
     │
   TP331
     │
 Q305集电极
     │
 Q305发射极
     │
    GND
```

因此：

```
RTC /INT = 高阻
TP334    ≈ 0.6～0.8 V
Q305     = 导通
TP331    = 低电平
```

这里“RTC_INT 处于高阻”只表示 RTC 不再吸收电流。整个节点仍然存在由 R 325 和 Q 305 形成的电流。

## 2. RTC 主动把 INT 拉低

如果 RTC 产生中断并使 `/INT` 导通：

```
TP334 → U305内部开漏MOS管 → GND
```

R 325 产生一条电流：

```
5 V → R325 → RTC_INT → U305 → GND
```

电流大约为：

```
I_R325 ≈ 5 V / 47 kΩ
       ≈ 106 μA
```

TP 334 被 RTC 拉到接近 0 V 后：

- Q 305 的基极约 0 V，Q 305 截止。
- Q 303 基极被拉低，PNP 管 Q 303 导通。

Q 303 的供电电流路径是：

```
V_5V_RTC
   │
 R318 47kΩ
   │
 Q303发射极
   │
 Q303集电极
   │
 TP331
   │
 R326及后级输入
```

R 318 限制 Q 303 能够提供的电流，理论最大值约为：

```
I_R318 ≈ (5 V - 0.7 V) / 47 kΩ
       ≈ 91 μA
```

因此：

```
RTC /INT = 拉低
TP334    ≈ 0～0.2 V
Q305     = 截止
Q303     = 导通
TP331    = 被弱上拉为高
```

这里 TP 331 的实际高电压取决于 R 326 后面的负载，因为 Q 303 的输出电流被 R 318 的 47 kΩ限制。

## 3. 两种状态总结

|RTC 输出状态|TP 334|Q 303 PNP|Q 305 NPN|TP 331|
|---|---|---|---|---|
| `/INT` 高阻|约 0.6～0.8 V|可能有微弱导通|导通|低|
| `/INT` 主动拉低|约 0～0.2 V|导通|截止|高|

注意：高阻状态下，由于两个三极管基极共接，Q 303 可能不会完全理想截止。可能存在一条受 R 318 限制的小电流：

```
5 V → R318 → Q303 → Q305 → GND
```

但 R 318 为 47 kΩ，该贯通电流最多大约几十微安，Q 305 通常仍会把 TP 331 压低。

## 4. 实际测量方法

关闭 RTC 中断后，建议测三个点：

```
TP334：预计约0.6～0.8 V
TP331：预计接近0 V
TP327：可能约1.2～1.5 V，具体取决于晶体管状态
```

所以不能用“TP 334 是否为 5 V”判断 RTC 是否高阻。因为 R 325 虽然把节点往 5 V 拉，但 Q 305 的基极—发射极会把节点钳位在约 0.7 V。

你的目标状态应当是：

```
RTC_WriteStatus = 0
TP334不再被RTC压在接近0 V
TP334升到约0.6～0.8 V
TP331变成低电平
```

这才是 U 305 的 `/INT` 已经进入高阻、后级上拉与三极管电路开始接管该节点的表现。
