# Elmos 是什么

[ELMOS-PSI5-E521.41 - ](../hardware/ELMOS-PSI5-E521.41%20-%20.pdf)

![](assets/2026.11.10%20高度传感器开发/file-20261110162933602.png)
<mark style="background: #FF5582A6;">
CH 1～CH 3 的 F 1 用于三路车身加速度，CH 1～CH 4 的 F 2 用于四路高度信号

每个通道可配置的 **6 个接收时隙（Time Slot**）</mark>


- **Elmos 给传感器供电**，传感器保持工作，线路上有静态电流。
- **Elmos 在线路上发出电压同步脉冲**，作为这一周期的时间起点。
- <mark style="background: #FF5582A6;">**传感器等待约定的时间后，通过改变线路电流发送数据帧**。</mark>
- 发完后，<mark style="background: #FF5582A6;">线路电流回到静态水平，等待下一个周期</mark>
- 
时间 →             同步        F 1 数据         F 2 数据       下次同步
              ↓                                        ↓
线路电压： ─  ─┌─┐─────────────────────────────────────┌─┐──
            └─┘                                                                    └─┘

线路电流： ────────     ▥▥▥▥──────────▥▥▥▥──────────────────
          静态                数据帧                数据帧                    静态

## 传感器是怎么知道他要发数据给 elmos 了？

**靠 Elmos 发出的“同步电压脉冲”。** 传感器内部有检测电路，检测到这个脉冲，就知道新一轮数据发送开始了。


Elmos：       发出同步脉冲
                   │
                   ├── 等待约 96 μs  → 接收 F 1
                   │
                   └── 等待约 256 μs → 接收 F 2
<mark style="background: #FF5582A6;">（传感器内部也有芯片和计时逻辑，能够按照设定的延时发送数据。）</mark>
传感器：      检测同步脉冲
                   │
                   └── 按自身约定的延时，改变线路电流发送数据
           
<mark style="background: #FF5582A6;">Elmos 每发一次同步脉冲，传感器就按约定时序返回这一周期的数据，无须 MCU 每次单独发送“读取高度”的命令。</mark>


## 传感器是如何跟 elmos 通信的，他怎么知道延迟多久的，可以配置吗

有些传感器允许配置发送延时，有些使用固定延时。

# PSI 5 协议是什么


**PSI 5 是一种用于汽车传感器与 ECU 通信的数字接口协议**，全称是 **Peripheral Sensor Interface 5**。它规定了接线方式、如何表示数据、数据帧格式以及发送时序。

它最显著的特点是：**用同一对导线同时完成供电和数据传输。** [TDK 传感器资料](https://www.micronas.tdk.com/sites/default/files/downloads/files/HAL_HAC_3980_Stray-field_Robust_3D_Position_Sensor_with_PSI5_Output_Interface.pdf)

结合你的原理图，一路接口就是：
![](assets/2026.11.10%20高度传感器开发/file-20261110175415517.png)

```
Elmos SIF1 ─── P_PSI5_SENSOR1 ─── 传感器
    GND   ─── P_PSI5_RTN1    ─── 传感器回路
```

**这两根线怎样同时供电、通信？**

|功能|实现方式|
|---|---|
|给传感器供电|Elmos 在线路上提供直流电压|
|Elmos 发送同步或命令|在线路电压上叠加脉冲|
|传感器返回数据|按编码规则改变从线路吸取的电流|

传感器会先把测量结果转换成数字，再通过电流变化发送出去。例如，测得的高度被编码成一串二进制位，Elmos 检测电流变化，将它们还原成数据。**电流的大小并不直接等于高度值。** [Elmos 手册](https://www.mouser.com/datasheet/2/594/e521-41_elmos_ds-949214.pdf)

PSI 5 使用 **曼彻斯特编码**：通过每个数据位中间的电流跳变表示信息，使接收端能够从波形中恢复位时序。常见通信速率为 **125 kbit/s、189 kbit/s**，你的项目配置为后者。

**数据按“帧”发送，典型结构可以理解为：**

```
起始位 → 测量数据或状态信息 → CRC 或奇偶校验
```

校验用于判断传输过程中数据是否出错。帧的数据长度、校验方式，需要传感器与 Elmos 配置一致。

PSI 5 还支持不同的发送方式：

|模式|传感器什么时候发送|
|---|---|
|异步模式|上电后按自身设定的周期发送|
|同步模式|检测到 ECU 的同步脉冲后，在约定的时隙发送|

**你的项目使用同步模式**。整个链路是：

```
S32K324 ── SPI ── Elmos ── PSI5 ── 传感器
```

其中，Elmos 负责 PSI 5 侧的供电、同步脉冲产生、电流信号接收和解码；S 32 K 324 通过 SPI 配置 Elmos、读取解码结果，再由软件转换成高度、加速度等应用数据。

## 初始化


```
IoHwAb_Dio_setVSIG_EN_Level(STD_ON);  // 打开 VSIG 供电使能
E52141_Set_nRES_HIGH;               // 拉高 Elmos 的复位脚

ST_E52141SPIDATA.u8_TxLen = 0U;
ST_E52141SPIDATA.E_RxFlag = E52141_SPI_IDLE;
ST_E52141RUNDATA.E_RUNST = E52141_InitRun;
// 清理其他内部状态……

Elmos52141_CreatInitData_Vbus();     // 生成首批 SPI 配置数据
```


代码注释要求 **SPI 已先初始化、NCS 保持高电平**，因为 Elmos 在 `NRES` 上升沿根据 NCS 电平选择 SPI/UART 模式。

Elmos 52141_SendTxBuf 是异步发送数据

CPU 提交 SPI 收发任务后，函数就可以返回；数据由 SPI 外设和 DMA 继续传输，完成后再通过中断通知软件。

<mark style="background: #FF5582A6;">这个项目实际使用的是 **LPSPI 2 + TX/RX DMA + 完成中断回调**，可以沿着代码看。</mark>

### 函数返回后，谁在发送？

一路使用 **LPSPI 2**，启用 DMA，TX、RX 分别使用逻辑 DMA 通道 0、1


发送数组 au 16_TxBuf
        │
        │ TX DMA 搬运
        ▼
LPSPI 2 发送 FIFO → 移位寄存器 → MOSI → Elmos
                                  ↑
                         LPSPI 2 产生 SCLK

接收数组 au 16_RxBuf
        ▲
        │ RX DMA 搬运
        │
LPSPI 2 接收 FIFO ← 移位寄存器 ← MISO ← Elmos


## DMA 完成后，通过中断调用完成回调


```
RX DMA 完成中断
    ↓
LPSPI 底层处理传输结束
    ↓
SPI 驱动完成 Job / Sequence 的收尾
    ↓
Sequence_0_Notification()
    ↓
Elmos52141_NotificationPoll()
    ↓
E_RxFlag = E52141_SPI_COMPLETE
```
