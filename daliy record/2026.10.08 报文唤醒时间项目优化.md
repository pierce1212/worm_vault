#### NVM 设置的 10 个存储 BLOCK 如何理解


![](assets/2026.10.08%20报文唤醒时间项目优化/file-20261010135823840.png)

可以理解为 DEM 的 10 个“故障档案存储槽”

DEM 主事件存储
├─ 槽 0 → NVM_ID_EVMEM_LOC_ 0 → 2000 字节
├─ 槽 1 → NVM_ID_EVMEM_LOC_ 1 → 2000 字节
│   …
└─ 槽 9 → NVM_ID_EVMEM_LOC_ 9 → 2000 字节

一个槽里面保存的是一条故障的完整档案：
```
故障档案
├─ 事件 ID、状态、计数等信息
├─ 冻结帧记录 1
├─ 冻结帧记录 2
└─ 扩展数据等
```


| 参数              | 含义            |
| --------------- | ------------- |
| **10 个槽**       | 能保留多少条故障的详细档案 |
| **每条 2 个冻结帧记录** | 每份档案能保存多少张快照  |
| **每块 2000 字节**  | 每份档案分配多大存储空间  |
|                 |               |


#### 冻结帧和扩展帧的区别

冻结帧就是快照，故障达到指定触发状态时，把那一瞬间的一组环境数据拍照保存下来。
电压、温度、转速等故障现场 → 冻结帧；
发生次数、老化计数、FDC、失败周期数 → 扩展数据；
