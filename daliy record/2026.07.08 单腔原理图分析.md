# 供电电路
![](assets/2026.07.08%20单腔原理图分析/file-20260709104534114.png)
![](assets/2026.07.08%20单腔原理图分析/file-20260709104932132.png)
VBATIN_1 是电机的供电输入
VBATIN_2 是控制器供电输入
这部分可以看成 **VBATIN_1 输入到 `BC/KL30_M` 的受控高边电源开关 + 保护滤波电路**。

## **1. 输入保护和滤波**

`VBATIN_1` 进来后，先经过：

- `ZD201`：TVS 管，跨在 `VBATIN_1` 和 `GNDIN_1` 之间，用来吸收电源线浪涌、ESD、load dump 类瞬态。
- `C206/C207/C208/C209`：输入端去耦滤波，覆盖不同容量和封装：
    - `4.7uF`
    - `2.2uF`
    - `1uF`
    - `470nF`

<mark style="background: #FFB8EBA6;">这些电容在 MOS 前端，作用是把线束侧的尖峰和高频噪声先压住。</mark>

## **2. Q 201 是主电源通断/反接保护 MOS**

`Q201` 是串在 `VBATIN_1 -> KL30_M` 路径上的大电流 MOS，型号看起来是 `IAUCN04S7N009`，低 Rds(on) 功率 MOS。

它的作用大概率是：

- 正常上电后导通，把 `VBATIN_1` 送到 `KL30_M`
- 反接、掉电、BE 13 未使能时关断
- 代替普通二极管做低损耗反接保护/高边开关

因为这是高边 N-MOS，所以 gate 不能只拉到 5 V，必须拉到比电池电压更高。这里就用到了下面的 `O_S_CP_BE13`。

## **3. `O_S_CP_BE13` 和 `CP_RVP` 是 gate 驱动链路**

**<mark style="background: #FFB86CA6;">`O_S_CP_BE13` 标注了 `VPWR+12V`，说明它来自 BE 13 的 charge pump，电压大约是电池电压再加 12 V。</mark>**

下方电路：

- `Q214`：NPN，受 `VCC_5V_1` 控制
- `Q204`：PNP，把 `O_S_CP_BE13` 送到 `CP_RVP`
- `R216/R218`：给 Q 214 基极做分压/下拉
- `R213/R215`：给 Q 204 做偏置
- `R210`：`CP_RVP` 到 Q 201 gate 驱动路径上的限流/阻尼电阻
- `D202/D204/R204`：gate 驱动保护、快速放电或 Vgs 钳位相关网络

工作逻辑是：

```
VCC_5V_1 有效
  -> Q214 导通
  -> Q204 被拉开
  -> O_S_CP_BE13 传到 CP_RVP
  -> Q201 gate 被抬高
  -> Q201 导通
  -> VBATIN_1 输出到 KL30_M / BC
```

如果 `VCC_5V_1` 没起来，或者 BE 13 的 charge pump 没输出，`CP_RVP` 不会有效抬高，Q 201 就关断。

## **4. L 201 + C 201/C 202 是输出侧滤波/储能**

Q 201 后面是 `KL30_M`，再经过 `L201` 到 `BC`：

- `L201`：串联电感/磁珠，抑制电源线上高频噪声
- `C201/C202`：两个 `330uF/35V` 大电容，给后级大电流负载提供储能，降低电压跌落 

所以右侧 `BC` 是经过保护、开关和滤波后的电池电源母线，后面大概率供电机高边、阀驱动或 BE 13 负载侧。

**一句话总结**

这块电路是：`VBATIN_1` 输入先做浪涌保护和去耦，然后通过 BE 13 charge-pump 控制的高边 N-MOS `Q201` 输出到 `KL30_M/BC`，最后用 `L201 + 330uF 电容` 做后级电源滤波和储能。

调试时重点量：`VBATIN_1`、`O_S_CP_BE13`、`CP_RVP`、Q 201 gate/source、`KL30_M`、`BC`。如果 `BC` 没电，先看 `VCC_5V_1` 和 `O_S_CP_BE13` 是否起来。

# 电机驱动


![](assets/2026.07.08%20单腔原理图分析/file-20260709135635291.png)
这部分是 **单向有刷电机/执行器驱动 + 电流采样**。真正的大电流不经过 U 204，而是走左边三个功率 MOS 和采样电阻。

## **1. 正常驱动时的大电流路径**

当电机需要转动时，通常是：

```
BC 电源
 -> MOTOR_HSD
 -> Q202 高边 MOS
 -> M+ 
 -> 电机 M201
 -> M-
 -> Q205 低边 MOS
 -> R221 采样电阻 1mΩ
 -> GND
```

也就是：

```
BC -> Q202 -> 电机 -> Q205 -> R221 -> GND
```

这里：

- `Q202` 是高边开关，负责把 `BC` 电源接到电机正端 `M+`
- `Q205` 是低边开关，负责把电机负端 `M-` 接到地
- `R221 = 1mΩ` 是电流采样电阻，所有主电流都会经过它

所以电机电流越大，`R221` 两端压降越大。

## **2. 电流采样怎么算**

`R221 = 1mΩ = 0.001Ω`

```
Vshunt = I_motor * 0.001Ω
```

例如：

```
10A  -> 10mV
50A  -> 50mV
110A -> 110mV
```

后面 `U203` 是运放，把这个很小的压降放大。图上写了：

```
Ipeak = 110A
Vout = 110 * 0.001 * 22 = 2.42V
```

说明放大倍数大约是 **22 倍**。

所以：

```
CSO ≈ I_motor * 0.001 * 22
CSO ≈ I_motor * 0.022V/A
```

换算一下：

```
10A  -> CSO ≈ 0.22V
50A  -> CSO ≈ 1.10V
100A -> CSO ≈ 2.20V
110A -> CSO ≈ 2.42V
```

这个 `CSO` 后面一般给 MCU ADC，用来判断电机电流、过流、堵转等。

## **3. Q 203 是续流/制动 MOS**

`Q203` 接在 `M+` 和 `M-` 之间，门极信号是 `FRW_G`，这个名字大概率是 **Freewheel Gate**。

当 Q 205 关断时，电机是感性负载，电流不能瞬间变成 0。此时需要给电机电流一个续流通道。

续流时可能是：

```
电机绕组电流
 -> M-
 -> Q203
 -> M+
 -> 电机内部
```

也就是 Q 203 把电机两端短接，让电流在电机和 MOS 内部循环衰减。

作用：

- 防止 M+/M- 电压飞高
- 降低尖峰
- 控制电机电流衰减速度
- 可以实现制动/续流

## **4. MOS 栅极电流不是主电流**

`PD_G`、`FRW_G`、`MTG_LS` 这些是门极控制信号，不是电机大电流。

比如：

- `PD_G` 控制 Q 202
- `FRW_G` 控制 Q 203
- `MTG_LS` 控制 Q 205

MOS 的 gate 像一个小电容，驱动时只是瞬间充放电：

```
开通瞬间：驱动芯片给 gate 充电
关断瞬间：gate 电荷被放掉
稳定导通后：gate 基本不持续消耗电流
```

所以真正的大电流走 MOS 的 D-S 通道，不走 gate。

## **5. 周围二极管和稳压管的作用**

`D203/D205/D206`、`ZD201/ZD202/ZD203` 这些不是正常主电流路径，主要用于：

- 钳位 MOS 的 `Vgs`
- 防止 gate-source 过压
- 吸收电机感性负载带来的尖峰
- 提供快速放电/保护路径

正常工作时，它们电流很小；只有开关瞬间、浪涌、反向尖峰时才明显导通。

## **6. C 203 + R 205 是吸收网络**

`C203` 和 `R205` 串联，跨在 `MOTOR_HSD` 和下方开关节点之间，作用类似 RC snubber。

它平时不走直流电流，因为电容隔直。只有电压快速变化时才有电流：

```
I = C * dv/dt
```

它用来减小 Q 202 开关时的尖峰和振铃，代价是会有一点开关损耗，能量主要消耗在 `R205` 上。

一句话总结：这块电路的主电流是 `BC -> Q202 -> 电机 -> Q205 -> R221 -> GND`；Q 203 负责续流/制动；R 221+U 203 把大电流转换成 `CSO` 电压给软件检测。


## 7. 注意点 M-与 Q 203 是连接的

Q 203 导通的时候，电机被直接短路，这种情况是：
短路制动 / 动态制动 / fast decay / recirculation

## 8. BE 13 端的作用
|信号|手册定义|在你这张图里的作用|
|---|---|---|
|`PD_D`|pump motor 高边 FET drain feedback|接 Q202 漏极/电源侧，用来检测高边 MOS 的 drain 电压|
|`PD_G`|pump motor 高边 FET gate control|驱动 Q202 的 gate，让高边 MOS PWM 导通|
|`VBOOT`|bootstrap capacitor for pump motor|外接自举电容，给高边 gate driver 提供高于 source 的驱动电压|
|`PD_S`|pump motor 高边 FET source feedback|接 Q202 source/电机 M+ 节点，作为高边浮动驱动参考点|
|`FRW_G`|active recirculation low-side FET gate control|驱动 Q203，用于主动续流/短路制动|
