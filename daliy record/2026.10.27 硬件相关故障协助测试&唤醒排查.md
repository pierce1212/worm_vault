## 第一帧报文接收到了，没有响应报文的原因？

1145 收到唤醒帧，INH 拉高
  → MCU 上电并初始化
  → CAN 控制器启动，进入软件唤醒验证
  → MCU 收到有效 NM 帧
  → EcuM 验证通过，通知 ComM
  → 通信启动，CanNm 进入 Repeat Message
  → 发送 0 x 60 B


CanNm_MainFunction()
  → CanNm_CaseRepeatMessage()    // RMS 状态处理
  → CanNm_MainFunctionTx()       // 判断是否满足发送条件
    → CanNm_MessageTransmit()
      → CanIf_Transmit()         // 发送 0 x 60 B

断点打在 CanNm_MainFunctionTx，可以发现这里已经判断 NM 处于 buS SLEEP 状态了。

## 5 E 4444 ECU RAM 故障

Mbist 上电自检时，或者 MCU 运行时 FCCU DCM 记录故障（双 BIT 不可纠正 ECC 错误 ，PRAM 0 多比特错误，PRAM 1 多比特错误）会报此故障。

由于响应时间要求，功能安全自检暂时取消，此故障暂时不测。后续如果功能安全需求存在，实现此 DTC。
