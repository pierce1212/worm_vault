### 当前子任务

![](assets/2026.11.16%20搞懂ITCM%20DTCM%20BACKDOOR的机制/file-20261116113334366.png)

<mark style="background: #FF5582A6;">**ITCM/DTCM 的 backdoor 机制，就是给同一块 TCM RAM 提供一条“通过系统总线访问”的入口。**本核可以直接访问，DMA、其他核等总线主设备则可以通过这个入口访问。这里的 backdoor 是硬件访问通路的名称。
</mark>
以 **S 32 K 3 / Cortex-M 7** 为例：

- **ITCM**：Instruction Tightly Coupled Memory，通常存放需要快速执行的代码。
- **DTCM**：Data Tightly Coupled Memory，通常存放栈、变量和实时计算数据。
- 它们属于软件管理的存储空间，内容不会像 Cache 那样自动换入、换出。[NXP S32K3 Memories Guide](https://community.nxp.com/pwmxy87654/attachments/pwmxy87654/S32K/37044/2/AN13388.pdf)

可以这样理解两条访问路径：

```
本核 CPU ── 专用 TCM 接口（frontdoor）─────┐
                                         ├── 同一块 ITCM / DTCM RAM
DMA / 其他核 ── 系统总线 ── backdoor ─────┘
```

Cortex-M 7 提供 **AHBS，也就是 AHB 从接口**，让系统侧设备能够访问 TCM；芯片厂商负责把它接入具体的总线和地址映射。[Arm Cortex-M7 接口说明](https://developer.arm.com/-/media/Arm%20Developer%20Community/PDF/Processor%20Datasheets/Arm-Cortex-M7-Processor-Datasheet.pdf?hash=5C37DFAA43B532B8BD2DB277685F76007FCFEAE5&la=en&revision=35233191-7cdb-429e-9170-e07ad9d87c7a)

**关键点是：<mark style="background: #FF5582A6;">两个地址窗口可以指向同一个物理存储位置</mark>。**

例如，假设某核 DTCM 的本地基址为 `0x20000000`，backdoor 基址为 `B`：

| 访问方式               | 访问地址         | 实际位置              |
| ------------------ | ------------ | ----------------- |
| 本核直接访问             | `0x20000020` | 该核 DTCM 偏移 `0x20` |
| DMA 通过 backdoor 访问 | `B + 0x20`   | 同一个位置             |

DMA 写入后，本核读取对应位置就能取得数据，**不需要硬件再复制一份**。其中 `B` 必须查具体芯片的 memory map。

为什么要这样设计？多核芯片中，各核都可能使用 `0x20000000` 作为“自己的 DTCM”地址。因此，其他核或 DMA 需要一个系统侧地址窗口，明确指定访问哪个核的 TCM。NXP 的 S 32 K 3 地址映射就是这种设计。[NXP 对本地地址与 backdoor 地址的说明](https://community.nxp.com/t5/S32K/S32K358-memory-map/m-p/2262417/highlight/true?profile.language=en)

实际使用时注意：

- **DMA 能访问什么地址取决于芯片连接。**在 S 32 K 3 中，DMA 访问 DTCM 要使用对应 backdoor 地址。
- **backdoor 访问包含系统总线传输和仲裁**，不能直接套用本核专用 TCM 通路的时延。
- **ECC 初始化有访问宽度限制。**NXP AN 13388 特别指出：其描述的 S 32 K 3 实现中，DMA 可通过 backdoor 初始化 DTCM，但不能用该路径的 32 位写来完成需要 64 位写的 ITCM ECC 初始化。[NXP 初始化要求](https://community.nxp.com/pwmxy87654/attachments/pwmxy87654/S32K/37044/2/AN13388.pdf)

可以把它记成：**TCM 是房间，frontdoor 和 backdoor 是通向同一房间的两条路；地址不同，访问的数据可以是同一份。**
